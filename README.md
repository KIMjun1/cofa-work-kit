# Cofa Probe Hackathon Work Kit

본 저장소는 대회 시작 전 사전 제작·공개한 **작업 방식 및 의사결정 기록 도구(지침·템플릿·하네스)**입니다.
특정 과제를 위한 보고서, 분석 코드, 도메인 지식은 없습니다. 범용 자료 요약 스크립트 1개(tools/profile_data.py)만 포함합니다.

## 1. 셋업 (과제 시작 직후 터미널에 붙여넣기)

```bash
git clone -q https://github.com/KIMjun1/cofa-work-kit.git /tmp/kit 2>/dev/null; bash /tmp/kit/setup.sh
```
- 갈림길은 없습니다. 마지막 "셋업 완료" 아래에 나오는 안내(있을 때만)를 그대로 따르면 됩니다.
- 첫 줄 `[1/5] 작업 폴더` 아래 목록이 왼쪽 파일 탐색기와 같은지만 눈으로 확인합니다.

- 그다음 터미널에 `codex`를 입력하고 Enter (IDE에 Codex 창이 따로 있으면 그 창을 씀, 당일 확인).
- 과제 설명이 화면이나 대화로만 주어지면, Codex에게 원문을 붙여넣고 "TASK.md로 저장하고 커밋해 줘"라고 말합니다.
- Codex 켠 직후: `/status`로 모델 확인 → `/model`에서 Sol 6.1과 추론 강도(high 이상) 선택. `/fast`는 켜지 않습니다(사용량 증가).

## 3. 말하는 법 (번호 대신 목적과 기준을 내 말로)
Codex는 셋업이 끝난 뒤 켭니다(AGENTS.md를 시작할 때 읽음). 예시이며 그대로 외울 필요는 없습니다.
| 단계 | 예시 문장 |
|---|---|
| P1 | 과제랑 자료부터 파악하자. 유형 후보와 근거를 보여 주고, 확정은 내가 할게 |
| P2 | 애매하거나 자료끼리 안 맞는 부분만 뽑아 줘. 해석은 빼고 |
| P2b | 구현형으로 간다. 서비스 설계는 추천 조합으로 한 번에 보여 줘 |
| P3 | 계획 세워 줘. 제일 위험한 곳도 같이 |
| P4 | "다음" 또는 "진행해" (Codex가 제안한 다음 단계를 실행. 번호를 몰라도 됨) |
| P5 | 독립 검증해 줘 (같은 창에서 진행) |
| P6, P7 | 끝내자 (제출 전 점검과 서술형 준비가 이어서 진행) |
- Codex가 "적용 예정:"이나 "건너뛸까요?"라고 물으면 맞는지만 보고 답합니다.
- **외울 것은 네 마디뿐입니다**
  1. 시작: "과제랑 자료부터 파악하자. 유형은 내가 정할게"
  2. 진행: "다음" / "진행해" / "추천대로" / "1번". **결정 질문에는 "1번, OO라서"처럼 번호와 이유를 한 줄로** (이유가 기록돼 점수 근거가 됨)
  3. 모르겠을 때: "쉽게 말해줘"
  4. 막힐 때: "이제 뭐 해?"
- 결정 질문이 아니어도 여유가 있으면 짧은 답에 내 판단을 한 마디 붙입니다. 예) "진행해. 단 그래프는 빼고", "2번. 시간이 부족해서". 이것이 의도 점수의 근거가 됩니다.
- **시간은 내가 화면 타이머로 관리합니다.** Codex는 시간을 모릅니다. 남은 50분에 "범위 줄이자", 40분에 "독립 검증하자", 20분에 "끝내자"라고 말합니다. 계획 때 Codex가 단계별 예상 분을 보여 주니, 남은 시간과 비교해 결정합니다.
- **순서가 기억나지 않으면 "이제 뭐 해?"라고만 물으면 됩니다.** Codex는 매 보고 마지막 줄에 `위치 · 다음 · 결정 필요`를 붙입니다.
- 서술형 메모는 마무리 때 화면에 나오고, 파일로는 왼쪽 목록의 **REVIEW.md 5번**에 있습니다. 서술형 화면으로 넘어가기 전에 꼭 읽고 외웁니다.

## 4. 구성 파일
- `AGENTS.md`: Codex 작업 규칙 (길잡이 역할, 대화 원칙, 단계 판단, 코드 계산, 설치 승인)
- `PLAN.md`: 과제 유형과 검증 방식, 문제, 성공 기준(R), 제출물, 가정(H)과 기각 조건, 단계(S)
- `PRD.md`: 구현형 과제일 때만. 3·6·7번은 역질문, 나머지는 가정 후 확인
- `DECISIONS.md`: 결정 기록 (선택, 근거, 버린 대안, 영향)
- `REVIEW.md`: 독립 검증표, 불일치 목록, 서술형 대비 메모
- `PROMPTS.md`: 국면별 지시문 P1~P7 (구현형은 P2b)
- `setup.sh`: 당일 셋업 스크립트 (README 1장 한 줄로 실행)
- `TOOLS.md`: 기본 패키지, 상황별 오픈소스 후보, 설치 제안 양식
- `tools/profile_data.py`: 환경 점검과 자료 요약 (당일엔 kit_tools/로 복사). 판별이 불확실하면 "확인 필요" 표시
